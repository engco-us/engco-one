# ENGCO Permitting & Forms Agent — Build Plan
Owner: Yusuf | Status: Active | Version 1.0

## Why this exists
Employees repeatedly retype the same real project numbers (gross SF, unit count, tank sizes, pipe specs — the same quantities the estimating toolkit already extracts with a citation) into standardized government forms: COMcheck/REScheck compliance certificates, City of Houston permit applications, TCEQ/county OSSF septic permits. That's the repetitive work worth killing first, not another drafting agent. This is the build-out of **A-03** in `data/agent_registry.json` (currently "Draft" status, no real tooling behind it), governed the same way estimating is: deterministic where possible, draft-only, human-approved, never auto-submitted to any agency.

## Already true (Phase 0 — done)
- A-03 exists in the registry with a real accountable owner and approval gate defined, but `owns_functions` is generic and no script exists yet.
- The estimating toolkit already produces most of the raw data these forms ask for (`scripts/estimating/extract_code_summary.py` for gross SF/unit count/stories; `build_kingwood_scope.py`-style project scopes for OSSF tank/capacity data).
- `pypdf` (6.14.2) and `pymupdf` are both available locally — real AcroForm field reading/filling is feasible without new dependencies.
- Real jurisdictions already touched this session, so real forms exist to test against: City of Houston (Kingwood water line permits), Montgomery County/TCEQ (Kingwood OSSF septic permit).

## Phase 1 — Source acquisition & verification
**Tasks**
- Locate the actual current form templates: Houston Permitting Center (houstonpermittingcenter.org) for City of Houston permit applications; TCEQ (tceq.texas.gov, Form 0574 family) and Montgomery County Environmental Health for the OSSF application; confirm whether COMcheck/REScheck have a fillable template at all or are only ever generated by DOE's own software (in which case there's nothing to "fill" — the agent's job there would be different: assembling the *inputs* DOE's tool needs, not filling a blank PDF).
- For each candidate PDF, verify it's a genuine, current, fillable AcroForm — not an expired revision, not a flat scanned image that would need a different (overlay) fill strategy.
- Save each verified source with its retrieval URL and date, same discipline as the leads-finder connectors.

**Exit criteria**
- At least 2 real, verified, fillable form PDFs saved under `data/forms/` with source + date recorded.
- Any form that turns out to be non-fillable or unavailable is documented as a real, honest gap — not assumed away.

**Real findings so far (2026-09-15)**
- Houston Permitting Center (houstonpermittingcenter.org) is real and the forms exist and are indexed (e.g. `/media/1036/download` — Application for Water/Wastewater Service), but the site sits behind a Cloudflare "Verify you are human" challenge on every page and even on direct file downloads (confirmed via `curl`, still challenged). Clicking through that is bot-detection bypass, which is off-limits — a human needs to grab these PDFs directly (they'll pass the check trivially) and hand them over, same pattern as the CAD-file gap on Kingwood.
- TCEQ does NOT host the actual OSSF permit application — the state delegates real OSSF permitting to counties, and TCEQ's own OSSF forms page only has a monthly agent-activity report. For Kingwood specifically, the real authority is Montgomery County Environmental Health.
- Montgomery County's OSSF application (`mctx.org`, "Residential – New Septic System" packet, dated 10/1/25) downloaded clean, no bot gate. But it's a **flat, non-AcroForm PDF** — checkboxes are literal "☐" glyphs and every field is a blank underscore line meant for a pen, not a form field `pypdf` can see (confirmed: `get_fields()` returns nothing). It also requires a wet-ink notarized signature and several physically-attached documents (3 sets of soil analysis, 3 sets of septic design, a utility letter, a POA) — this form can never be fully "submitted" by any agent regardless of tooling. A fill engine here means a coordinate-overlay (print text at the right x/y over the blank lines, like `render_scope_pdf.py` already does with reportlab) rather than the clean field-name fill Phase 3 assumed — real, still buildable, just fragile to the form's layout changing.

## Phase 2 — Field-mapping schema
**Tasks**
- Build a small inspector script (`scripts/permitting/list_form_fields.py`) that reads a form's real AcroForm field names via pypdf — never guessed from visual layout.
- For each field, map it to either (a) an existing real data source (`project_registry.json`, a project's `scope_of_work.json`) or (b) explicitly "human-required" — the same "not_found beats a guess" rule as every extractor before this.
- Store each mapping as a schema file, e.g. `data/forms/houston_water_permit.schema.json`.

**Exit criteria**
- Every real field on a verified form is accounted for — mapped to a source or explicitly flagged — none silently skipped.

## Phase 3 — Deterministic fill engine
**Tasks**
- Build `scripts/permitting/fill_form.py`: given a project ID + a form schema, fill the real AcroForm fields via pypdf and emit a draft PDF. No field value is ever invented — a schema-mapped field with no data in the project record stays blank, not guessed.
- Test end to end against ENG-2026-002 (Kingwood) real data, since that's the one project with both a real form target and real extracted quantities already on hand.

**Exit criteria**
- A real draft-filled form produced from Kingwood's actual project data, every filled value traceable to its source, verified by a human reading it side by side with the source data before it's trusted.

## Phase 4 — Register as a real agent
**Tasks**
- Update A-03's `owns_functions` and status once Phase 3 is proven, same as A-05 was updated after the estimating toolkit proved itself.
- Wire a "Prepare permit forms" action into `product/`'s task lifecycle, same governed pattern as estimating's `/api/tasks/[id]/analyze` route — draft-only, the human owner reviews and submits (or doesn't) themselves. No agent ever submits a form to a government agency.

**Exit criteria**
- An employee can request forms prep from the New Work composer and get back a real, cited draft — not a CLI script only I can run.
