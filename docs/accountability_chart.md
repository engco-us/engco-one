## Decision: no formal departments (yet)
At current headcount (~8), hard departments add handoff friction without the staffing to support them. The seats above are functional accountability, not org silos — people still work across functions. Revisit when a function has dedicated headcount (e.g., a second engineer not also doing BD).

## Decision: lean start, not full 7-agent/22-SOP rollout
Full system stays as the scaffold to grow into. Actual starting operating rhythm:
1. Weekly scorecard (active projects, proposals out, cash position) — see Phase 2.
2. Two SOPs first: project intake/numbering (SOP-001), daily field reporting.
3. One agent active first: A-05 (Construction/Field), supporting Shawqi — highest leverage, lowest risk (drafts only, human review).
